# SparseMSE 2.0.2

* Maintainer changed to Bernard W. Silverman.
* The package is now explicitly deprecated and users are directed to
  `MultipleSystemsEstimation` for current development and support.
* Added a suppressible package startup message and package-level documentation.
* Updated the package description, arXiv reference and an obsolete documentation URL.
* Replaced logical abbreviations `T` and `F` in executable code by `TRUE` and `FALSE`.
* No substantive statistical-method changes were made.
